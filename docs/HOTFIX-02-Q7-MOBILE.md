## 2. 真实上传还是模拟响应

**模拟响应（UI 模拟验收）**，原因与边界：

- 测试实例在 `127.0.0.1:13010`，与 H5 的 `https://sh.scqfls.cn` **跨域**，浏览器会被 CORS 拦；
- 因此上传/会话响应通过**页面内 XHR 层桩**返回（仍完整走 `uploadMedia()` → `onload` → 组件状态机）；
- **生产媒体上传零发生**（直接打到上传口的 POST 全部被本地拦掉）。

> **模拟上传成功 ≠ 真实上传成功。** 真实上传链路的边界已在
> `MEDIA-50M-BOUNDARY-01`（独立实例）单独验收，本报告不重复主张。

不是只看 `scrollWidth == clientWidth` —— 控件可见性与可点尺寸都单独量了。
