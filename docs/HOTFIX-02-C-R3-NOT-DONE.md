**`session=0 / upload=0`** 说明：**组件的上传流程根本没有启动** ——
不是"拦截了但响应不对"，而是**文件设置后 `change` 没被组件的处理器接住**。

### 最可能的原因（未验证到底，按令不再猜）

| 可能 | 说明 |
|---|---|
| 该 input 处于 `disabled` | 模板里它随 `uploading \|\| disabled \|\| !canAddMore` 变灰；若初始态即禁用，设文件不触发 |
| 该 input 只服务"相册"路径 | 录音走的是 `document.createElement('input')` 动态创建（源码第 327 行），**是另一个 input**，我点错了目标 |
| label 包裹 + 隐藏 | 元素是 `<label>` 内的隐藏 input，`setFileInputFiles` 对隐藏元素在部分版本不派发 change |

第二条可能性最大：**录音入口和相册入口不是同一个 input**。
