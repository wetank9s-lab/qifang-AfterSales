### ⚠️ 本轮修了一个真实 bug：重置不生效

**现象**：点「重置」后请求仍带 `keyword=合成丁`，total 仍是 29。

**原因**：`load()` 是 `useCallback` 且读闭包里的 `keyword`，而 `reset()` 里 `setKeyword('')` 是**异步**的——同一次调用里闭包还是旧值。

**修法**：`load(p, ps, kw, sc, rg)` 改为**显式接收条件**，`reset()` 直接传空值：

```ts
void load(1, pageSize, '', '', ['', '']);
```

复验：重置后 `page=1&pageSize=20`、122 条 ✓

### 跨店负向（沿用上轮）

A 读 `id=1`（S02）→ **404**；B 读 `id=1` → **200**。修复未被本轮的 UI 改动破坏。
