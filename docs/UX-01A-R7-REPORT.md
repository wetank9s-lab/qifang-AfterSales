## 一、P1-① 工作台工单弹窗：**服务端分页**（已完成）

**修改**：`src/client/store-workbench.tsx` —— 新增 `TicketListPaged`（替换原"一次取 30 条"的 Body），`openFilteredList` 改为挂载它。

**实现**：
- `serviceTickets:list?page=&pageSize=&sort=-createdAt,-id&filter=…` —— **只请求当前页**；排序 `-createdAt,-id`（同时间用唯一 id 兜底，翻页稳定）。
- 总数取服务端 `meta.count`（授权范围内）；页码/总数/上一页/下一页；每页 10 ↔ 20（**切换即回第 1 页**）。
- **过期请求丢弃**（`seq` 序号，快速翻页不被慢响应覆盖）；页码失效自动校正到最后一页。
- 失败显示「加载失败 + 重试」（**绝不显示成 0 条**）。
- 状态筛选与分页参数**同时**由同一 `filter` 传入（概览卡 = 服务端同一 filter）。

**真实浏览器证据**（同一门禁）：
```

✓ P1-① 总数来自服务端 meta.count —— 共 194 条（首屏 10 行）
✓ P1-① 翻到第 2 页且内容变化 —— 第2页首行=FW20261014-0105
✓ P1-① 切每页 20 条并回到第 1 页 —— size=20 page=1 rows=20
✓ P1-① 分页后点工单号打开的是本行详情 —— 「工单 FW20261014-0115」
✓ P1-① 关闭详情后列表保持原页码/筛选 —— page=1 size=20
✓ P0 列表弹窗 → 工单号 → 详情在最上层 —— drawerZ=2001 · modalZ=2000
```
