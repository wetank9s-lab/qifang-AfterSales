## 一、member 页面授权核查

### 1.1 根因：平台机制，不是迁移

`@nocobase/plugin-client/dist/server/server.js:214-227`：

```js
this.app.db.on("roles.beforeCreate", async (instance) => {
  instance.set("allowNewMenu",
    instance.allowNewMenu === void 0 ? ["admin","member"].includes(instance.name) : !!instance.allowNewMenu);
});
```

新建菜单时**自动**绑给 `allowNewMenu=true` 的角色。实测 `roles` 表：`admin=t / member=t`，其余业务角色全 `f`。

**两条写入路径可区分**：member/admin 的 `rolesDesktopRoutes.createdAt` 落在**整秒**（`.2+00`），迁移写入是**微秒级** ⇒ 不是同一路径写入的证据。

迁移 `PAGE_ROLES` 明确不含 member：
