### B-17（**P1**）后台 SPA 初始化 403 → 偶发 "No permissions" 提示

- **现状**：任何业务角色登录后台首屏都会请求 `GET /api/environmentVariables?paginate=false` → **403**
  （`attachments/*.png` 头像请求同为 403，`<img>` 静默失败）。3 秒 toast，**不影响任何业务流程**。
- **定性**：**全局后台 P1 体验缺陷**（不是某页特有、不是 UX-01C 引入）。
- **修复硬约束（不得违反）**：
  1. **不得放宽 B-8**：平台元数据对业务角色保持 fail-closed；
  2. **不得放开环境变量读取**（表内含 DB 口令 / AES 主密钥等）；
  3. **不得把私有附件访问改成公开**（含 `attachments`、客户媒体）。
- **可选方向（需单独评审）**：收回业务角色的平台 `pm.*` snippets（改角色语义）；或接受噪声并在运维文档说明。
- **取消判据**：业务角色后台首屏**不再出现该 toast**，且上述三条约束的守卫断言仍全绿。详见 `docs/BACKLOG.md` B-17。

### B-19 短信宝端到端不可用（`SMS_TEMPLATE_ENV_PREFIX` 缺 `smsbao` 映射）

- **现状**：`SmsbaoProvider` 已实现，但 `templateCodeFor()` 恒返回空 ⇒ 每条发送被 `SMS_TEMPLATE_NOT_CONFIGURED` 拒。
  后台「短信通知」页已把它标为 **不可发送** 并写明原因（这是**正确展示**，不是能力可用）。
- **纪律**：**短信通知页 PASS 不能作为关闭 B-19 的依据**。B-19 保持独立待办。
- **影响面**：**是否阻断发布取决于首发服务商**——首发选阿里云则 B-19 不阻断；首发选短信宝则**阻断**。
- 详见 `docs/BACKLOG.md` B-19 与 `docs/DEVIATIONS.md` DEV-207。
