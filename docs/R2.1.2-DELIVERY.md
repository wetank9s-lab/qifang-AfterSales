## 七、本轮修掉的判据缺陷（都是"我自己骗自己"的类型）

1. **折叠分组没展开就点菜单** ⇒ `no-box`。根因：admin 组默认折叠，子孙 `<a>` 的 rect 全为 0。
   修法：先真实点击分组标题（`data-collapsed` 1→0）再点菜单项。
2. **按钮只测到「详情」** ⇒ 只扫可见 pane 且默认页签恰好全是已结束单。
   修法：逐页签切换 + 每个页签内取**真实数据行**里的按钮。
3. **工单号 `text:""` 却判"未截断"** ⇒ 量到了空行。修法：找第一个含 `[data-primary-action]` 的行。
4. **筛选区宽度 1158** ⇒ 量到的是整张表格容器。修法：改为统计筛选区块内输入控件与残留按钮数。
5. **`meta.count` 当隔离判据** ⇒ 本产品的 list action **不带 scope**（497 ≈ 全库）。
   修法：以「界面可见行 + 行内门店名」取证，并先用 SQL 核实账号的门店绑定与工单分布。
6. **`paginate=false` 会丢 scope 过滤** ⇒ 与第 5 条同源，必须用默认分页（界面真实路径）。
