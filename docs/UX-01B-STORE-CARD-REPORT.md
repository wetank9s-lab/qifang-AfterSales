## 2. 改了什么

### 门店卡
| 项 | 改前 | 改后 |
|---|---|---|
| 对齐 | `text-align: center` | **左对齐**（长地址折行不再居中撕裂） |
| 内边距 | 继承 `.svc-card` 14px | **12px 14px** |
| 店名 | 19px | **18px**（仍是最醒目一级） |
| 电话 | `inline-block`、16px、无标签 | **`☎ 门店电话 028-…`**，一行、可拨（`tel:`） |
| 地址 | 13px、无图标 | **`📍 地址`**、13px、**默认 2 行省略** |
| 展开 | 无 | **「展开完整地址 / 收起地址」**（只在真的溢出时出现） |
| 空值 | 已有 `v-if` 不渲染 | 保持（电话/地址为空不留占位） |

**展开判据用真实渲染高度**（`scrollHeight > clientHeight + 1`），不用字数——字数阈值在 375/420 屏会误判。且**只在收起状态测一次**，否则展开瞬间按钮消失、用户收不回去。

### 间距
- 门店卡 `margin-bottom: 12 → 10px`
- 本页 `.svc-field` `16 → 14px`（**scoped，只影响本组件**）

### 媒体区（未改）
- 仍 2×2（拍照 / 相册 / 录音 / 拍视频），**触控高度实测 74px ≥ 64px**
- 辅助文案保持一句「任选一种即可说明问题。」
